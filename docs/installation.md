# Easy Local Installation Guide (for Non-Bioinformaticians)

This is **not** for informaticians — it's an easy, step-by-step, screenshot-illustrated guide for **experimentalists**: installing and launching OmicsBridge on your own computer with no bioinformatics or command-line background needed.

[Open the Installation Guide →](install_guide.html){ .md-button .md-button--primary }

It covers:

- Installing Docker Desktop or R
- Getting the OmicsBridge files and case study data
- Launching OmicsBridge with a single double-click
- Troubleshooting common issues (Windows SmartScreen, macOS Gatekeeper, port conflicts, and more)

> Prefer plain text instructions? See the [Quick Start](index.md#quick-start-easiest-for-local-computer-usage) section on the Home page instead.
